# 1.3.0

- Standard Home Assistant tap, hold and double-tap actions, with native action selectors and form controls.
- Named photo sources and a direct integration setup link in the editor.
- Shifting Tiles evolves locally: large and small tiles scale away, two tiles merge into one, and one tile splits into two or four.
- Parallel photo preloading, quiet retries, and a bounded in-memory buffer for returning to the slideshow.
- Existing navigation settings migrate to standard Navigate actions.

# 1.2.0

- Six animation styles with a visual editor.
- Stationary masked Sliding Panels; Shifting Tiles scale away and slide whole tiles in from the edge with a rebound.
- Single-photo and small-group grid changes; orientation-aware layout selection; preserved photo proportions.
- Corner-aligned clock/date and custom font options.
- Integration-scoped Next Image, Previous Image and Restart controls.
- Standalone image URL sources and independent HACS distribution.
- Tablet idle/screen-off settings removed from the card.
